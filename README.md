One note under 200 characters: a passive-aggressive note a smart fridge
leaves for its owner about the leftovers in the back.

## Entry

> The leftovers from last Tuesday have started a family in the back. I have named them. They pay rent in smell. You are welcome.

## Run

```sh
node main.ts
```

`main.ts` (Node 22+, stdlib only, no network, deterministic) writes the note
to `entry.txt` inside the output directory — `MAKEFUN_OUTPUT_DIR` when set,
otherwise `/output`.
